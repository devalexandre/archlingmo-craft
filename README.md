# archlingmo-craft

The [archlingmo-craft] pacman repository of ArchLingmo: the storytold "Craft" apps
(github.com/storytold), the developer's own Arch packages, checked against pinned
sha256 sums and inspected before they are mirrored here. Optional apps, installed
from the Lingmo Store; pre-alpha.

The packages and the database are the assets of the `x86_64` release:

    [archlingmo-craft]
    SigLevel = Optional TrustAll
    Server = https://github.com/devalexandre/archlingmo-craft/releases/download/$arch

Published by `scripts/publish-craft.sh` (lingmo workspace). Don't upload by hand.
